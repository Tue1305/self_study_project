## 📚 Project Overview & Learning Objectives

This is a **personal self-study project** built to gain hands-on experience with modern Java backend architecture, stateless security, and containerization. 

### Core Concepts Practiced:
* **Stateless Authentication:** Implementing JWT generation, signing, and parsing using the `io.jsonwebtoken` (JJWT) library.
* **Spring Security 6 Pipeline:** Building a custom `OncePerRequestFilter` (`JwtAuthenticationFilter`) to intercept HTTP requests and validate Bearer tokens.
* **Application Containerization:** Writing a `Dockerfile`, building lightweight images, and managing Docker containers via CLI.
* **Full-Stack Integration:** Serving frontend static assets directly via Spring Boot's internal static resource handler (`/resources/static`).
